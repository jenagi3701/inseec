# inseec

## 🐔 MARKETRACK

A job search and AI application assistant for marketing careers, built as a local prototype in HTML, CSS and vanilla JS. It stores everything in localStorage and needs no backend.

Open [`market-track/index.html`](market-track/index.html) in a browser. Read [`market-track/README.md`](market-track/README.md) for the demo flow, features, architecture and honesty notes. Job offers are fictional demo data, and the AI runs locally.
