# inseec

## 🐔 Chic Career

A job search and AI application assistant for marketing careers, built as a local prototype in HTML, CSS and vanilla JS. It stores everything in localStorage and needs no backend.

Open [`chic-career/index.html`](chic-career/index.html) in a browser. Read [`chic-career/README.md`](chic-career/README.md) for the demo flow, features, architecture and honesty notes. Job offers are fictional demo data, and the AI runs locally.
